# 모바일 청첩장 웹 애플리케이션 디자인 명세서

- **작성일**: 2026-07-31
- **대상 커플**: 신랑 김희재 & 신부 이해연
- **예식 일시**: 2026년 9월 12일 토요일 오후 12:00
- **예식 장소**: 경기 파주시 탄현면 헤이리마을길 76-12 웨딩마을

---

## 1. 개요 (Overview)

모바일 화면에 최적화된 고급스럽고 세련된 **모던 & 미니멀 다크 럭셔리 스타일의 반응형 모바일 청첩장 웹 애플리케이션**입니다. 
전체 28장의 웨딩 사진 화보와 예식 정보, 실시간 카운트다운, 카카오/네이버/티맵 길찾기 딥링크, 원터치 계좌번호 복사, 참석 여부 전달(RSVP) 기능을 포함합니다.

---

## 2. 디자인 파트 (Design Specs)

### 2.1 테마 및 색상 시스템 (Color Palette)
- **Background**: `#121316` (스모키 딥 차콜)
- **Card Background**: `#1A1C20` (카드 배경, Border: `#2A2D35`)
- **Primary Text**: `#F4F4F6` (오프 화이트)
- **Secondary Text**: `#9A9EA7` (소프트 차콜 그레이)
- **Accent Color**: `#D4AF37` / `#C5A880` (소프트 럭셔리 골드)
- **Shadow & Overlay**: `rgba(0, 0, 0, 0.6)`

### 2.2 타이포그래피 (Typography)
- **English Header / Numbers**: Cormorant Garamond (Google Fonts)
- **Korean Header**: Noto Serif KR (Google Fonts)
- **Body & Controls**: Noto Sans KR / Inter (Google Fonts)

## 3. 기능 및 섹션 구성 (Sections & Features)

### 3.1 메인 히어로 섹션 (Hero Section)
- 대표 화보 이미지 배너 오버레이 (`pics/` 폴더 내 대표 이미지)
- 신랑 김희재 & 신부 이해연 서명 타이포
- 예식 일시 (`2026.09.12 SAT 12:00 PM`) & 장소 (`파주 웨딩마을`)
- **실시간 D-Day 카운트다운**: 2026년 9월 12일 12시까지 남은 일/시/분/초를 실시간 계산 및 표시

### 3.2 모시는 글 & 연락처 (Invitation & Contact Section)
- 감성 모시는 글 문구
- 신랑 **김희재** / 신부 **이해연** 이름 명시
- **직통 연락처 버튼**:
  - 신랑 연락처 (`010-3955-0256`): 전화 걸기 (`tel:`) / 문자 보내기 (`sms:`)
  - 신부 연락처 (`010-7244-4495`): 전화 걸기 (`tel:`) / 문자 보내기 (`sms:`)

### 3.3 웨딩 갤러리 섹션 (Gallery Section)
- `pics/` 디렉터리의 28장 사진을 최적화하여 2열/3열 그리드로 배치
- **모달 라이트박스 (Lightbox Slider)**:
  - 사진 클릭 시 전체 화면 모달 오픈
  - 슬라이드 좌/우 이동 버튼, 키보드 방향키 support, 터치 스와이프 지원
  - 닫기 버튼 및 썸네일 카운트 표시 (예: 3 / 28)

### 3.4 오시는 길 & 교통 안내 (Location & Map Section)
- 예식장 주소: `경기 파주시 탄현면 헤이리마을길 76-12 웨딩마을`
- **지도 연동**: Kakao Static Map / Embed 지도 카드
- **원터치 길찾기 버튼**:
  - 네이버지도 바로가기 (`nmap://` 및 웹 URL)
  - 카카오맵 바로가기 (`kakaomap://` 및 웹 URL)
  - 티맵 바로가기 (`tmap://` 및 웹 URL)
- **주차 안내**: `예식장 내 무료주차 가능`
- **대중교통 안내**:
  - **좌석버스 (2200, 2200-1)**: 홍대입구역 1번 출구 - 합정역 1번 출구 - 법흥3리 헤이리커뮤니티하우스 하차
  - **시내버스 (900)**: 킨텍스역 - 대화역 - 탄현역 - 금촌역 - "민들레 병원" 하차

### 3.5 마음 전하실 곳 (Account / Congratulatory Fund Section)
- 신랑측 / 신부측 접이식 AccordionUI
- **신랑측 계좌**: 신한 `110-436-024423` (예금주: 김희재)
- **신부측 계좌**: 농협 `356-08-53534283` (예금주: 이해연)
- **[계좌번호 복사]** 버튼:
  - 클릭 시 `navigator.clipboard.writeText` 실행
  - 복사 완료 토스트 메세지 ("계좌번호가 복사되었습니다") 표출

### 3.6 참석 여부 전달 (RSVP Section)
- 구분 선택: [신랑측] / [신부측]
- 성함 입력
- 연락처 입력
- 동석 인원수 선택
- 식사 여부: [식사함] / [식사 안함] / [미정]
- 축하 메세지 작성 폼
- 제출 시 로컬 처리 후 축하 모달 안내 표출
