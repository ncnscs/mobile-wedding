# B컷 갤러리 및 축하 메시지 반응형 인터랙션 설계서

## 1. 개요
모바일 청첩장의 RSVP 섹션 및 갤러리 섹션에 다음 기능 2가지를 추가합니다:
1. **축하 메시지 실시간 반응 문구**: 하객이 RSVP 축하 메시지 텍스트박스에 글자를 입력하기 시작하면, 텍스트박스 하단에 작고 귀여운 감동 메시지가 부드럽게 등장하는 애니메이션.
2. **비밀 B컷 갤러리 (B-Cut Gallery)**: 메인 갤러리 하단에 잠긴 상태의 B컷 갤러리 섹션을 두고, RSVP에서 축하 메시지를 남겨 응답한 하객에 한해 잠금이 해제되며 미공개 화보를 감상할 수 있는 기능. (로컬 스토리지에 해제 상태 유지)

---

## 2. 세부 기능 및 UX/UI 설계

### 2.1 축하 메시지 작성 시 감동 안내 문구
- **위치**: RSVP 폼의 `#rsvp-msg` (textarea) 직하단
- **문구**: `"헉! 설마 축하메시지를 써주시는 건가요...?! 정말 감사드립니다!"`
- **인터랙션 및 애니메이션**:
  - `#rsvp-msg`의 `input` 이벤트를 감지합니다.
  - 텍스트 입력값(`value.trim()`)이 1자 이상일 경우, `.show` 클래스를 부여하여 높이와 투명도, 슬라이드 다운 애니메이션으로 부드럽게 표시합니다.
  - 입력값을 모두 지우면 부드럽게 슬라이드 업 및 페이드 아웃으로 사라집니다.
- **스타일링**:
  - 작은 글씨 크기 (`0.82rem`), 따뜻한 핑크/골드 톤, 라운딩 박스 또는 말풍선 스타일.
  - 살짝 살랑거리는 펄스/하트 아이콘 포함.

---

### 2.2 비하인드 B컷 갤러리 (B-Cut Gallery)
- **위치**: 기존 메인 갤러리 섹션(`gallery-section`) 바로 하단에 별도 B컷 카드/섹션 생성.
- **상태 관리**:
  - `localStorage.getItem('wedding_bcut_unlocked') === 'true'`로 해제 여부 파악.

#### [잠김 상태 (Locked State)]
- **디자인**: 은은한 글래스모피즘 카드로 '🔒 비하인드 B컷 갤러리' 표시.
- **안내 문구**: "RSVP 작성 시 소중한 축하 메시지를 남겨주시면 신랑·신부의 미공개 B컷 화보가 오픈됩니다 💕"
- **CTA 버튼**: `[ 축하 메시지 남기고 B컷 열기 ✍️ ]` 클릭 시 RSVP 입력창 `#rsvp-msg`로 부드럽게 스크롤 및 포커스.

#### [잠금 해제 상태 (Unlocked State)]
- **해제 조건**: RSVP 작성 후 [참석 의사 전달하기] 버튼 제출 시, `#rsvp-msg`가 비어있지 않으면 해제.
- **해제 애니메이션**: 자물쇠 아이콘이 `🔓` 또는 `✨` 로 바뀌며 반짝이는 파티클 효과와 함께 B컷 갤러리 그리드가 부드럽게 펼쳐짐.
- **B컷 사진 구성**: 미공개 B컷 화보 6~8장 그리드 배치 (라이트박스 클릭 시 크게 보기 연동).
- **RSVP 완료 팝업 연동**: RSVP 제출 완료 모달에 "🎉 축하해주셔서 감사드립니다! 특별히 B컷 갤러리도 보고 가실래요?" 문구 및 `[ B컷 갤러리 구경하기 ]` 버튼 추가.

## 4. 검증 계획
1. **텍스트박스 입력 테스트**:
   - RSVP 축하 메시지 입력 시 문구가 슥 나타나는지, 지울 때 부드럽게 사라지는지 확인.
2. **B컷 잠금/해제 테스트**:
   - 메시지 없이 RSVP 제출 시 B컷 잠금 유지 확인.
   - 메시지 작성 후 RSVP 제출 시 B컷 갤러리가 부드럽게 해제되고 사진이 정상 렌더링되는지 확인.
   - 페이지 새로고침 후에도 B컷 해제 상태가 저장되어 유지되는지 확인.
3. **모바일 responsive 및 라이트박스 확인**:
   - 모바일 화면 비율에서 B컷 그리드 및 라이트박스 터치 스와이프 정상 동작 검증.
